# Reporting security issues

For a suspected vulnerability, use this repository's GitHub Security tab to report it privately if private vulnerability reporting is enabled. If it is unavailable, ask the maintainer for a private reporting channel without disclosing exploit details publicly. No private contact address is configured in this source template.

Include the affected version, Android/WebView version, reproduction steps, impact and a minimal safe test case. Do not include private files, credentials or live signed URLs in a public issue.

Version 2.7.0 is the current development baseline. There is no promised support window or response SLA. App privacy behavior and permission boundaries are documented in docs/PRIVACY.md.
