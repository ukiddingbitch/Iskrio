# Screenshot provenance

The PNG files capture the current Iskrio 2.7 editor UI rendered from the same app assets in Chromium at a 412 × 915 CSS-pixel viewport (2× density). They are UI screenshots, not pictures captured from a physical Android phone. Device rendering may differ.

The demonstration landscapes were drawn procedurally for these captures. The library, captions, Track arrangement and illustrative waveform are demo data. No personal project, social-media post, third-party photograph or proprietary editor asset is included. The screenshots and original demo artwork use the Iskrio-authored MIT grant.
